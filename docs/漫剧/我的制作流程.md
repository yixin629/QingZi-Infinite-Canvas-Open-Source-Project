> 最后更新：2026-10-21。配合阅读：[作者流程总结](作者流程总结.md)、[分镜智能体提示词](提示词-分镜智能体.md)、[人物场景智能体提示词](提示词-人物场景智能体.md)。

## 二、启动（每次开工）

在项目目录 `QingZi-Infinite-Canvas-Open-Source-Project` 下：

1. 双击 `start.bat`：启动画布（10027）和任务服务（8089），两个黑窗口都别关。
2. 要用 ChatGPT 出图时，双击 `start-chatgpt-bridge.bat`：会弹出一个独立的 Chrome 窗口（7960）。
3. 浏览器打开 http://127.0.0.1:10027 。这是本机自用版，不需要登录。

## 三、ChatGPT 出图桥接（一次性设置）

原理：`bridges/chatgpt_image/server.py` 对画布假装成 OpenAI 图片接口，内部用 Playwright 控制一个独立的真实 Chrome 窗口，复用你在里面手动登录过的 ChatGPT 会话来出图。不改动画布核心代码。

1. 双击 `start-chatgpt-bridge.bat`，在弹出的 Chrome 窗口里**手动登录 ChatGPT**。用邮箱密码登录最稳；用 Google 账号登录可能被 Google 拦截。登录状态保存在 `data/chatgpt_bridge_profile/`，下次不用再登。
2. 画布 → 头像 → **MyApi 配置** → **图片** 页签 → 添加模型：
   - Base URL：`http://127.0.0.1:7960`
   - 模型名：`chatgpt-web`
   - Key：随便填一个，比如 `local`
3. 点「测试连接」：桥接会秒回，不会真的出图。

注意事项：
- 一次只出一张，排队执行；每张大约 1～3 分钟。
- 出图时 Chrome 窗口会自己操作，**别去点它**，也别关掉它。
- 遇到人机验证或重新登录时，到那个窗口里手动处理，然后在画布里重新点生成。
- ChatGPT 网页改版后可能失效（输入框、发送按钮的定位变了），到时需要更新 `server.py` 里的选择器。
- 这是用你自己的账号低频自用；平台条款不允许大规模自动化，别拿来批量刷图。

## 四、每一集的制作步骤

### 第 1 步：分镜
1. 打开分镜智能体对话：第一次先粘贴 [分镜智能体提示词](提示词-分镜智能体.md)。
2. 粘贴一章小说原文，得到整章规划和各视频编号的分镜。
3. 检查连续性和台词，需要的话让它「只重写视频编号XX」。

### 第 2 步：人物、场景、道具提示词
1. 打开人物场景智能体对话：第一次先粘贴 [人物场景智能体提示词](提示词-人物场景智能体.md)，并定好画风。
2. 把本章分镜贴给它，告诉它哪些资产已经出过图。
3. 得到新增资产的 GPT 提示词；场景要用 MJ 时说「这个场景用 MJ」。

### 第 3 步：出资产图
1. 画布里每个资产建一个图片节点，**节点名 = 资产名**（人物只写人名）。
2. 人物：图片节点选 `chatgpt-web` 模型，粘贴提示词后生成。
3. 场景：在 MJ 里出 3～4 张，挑一张拖进画布对应节点；或者也用 `chatgpt-web`。
4. 不满意就在节点上重新生成或换参考图，直到人物定稿。

### 第 4 步：视频（开通 Seedance 后）
1. 每个视频编号建一个视频节点，命名为「视频编号XX」，粘贴整段分镜。也可以把整章分镜交给画布助手「小庆子」，让它按视频编号批量建节点。
2. 让「小庆子」把提示词里的人物名和场景名做成 @引用，并连线到对应的资产节点。
3. 选 Seedance 2.5（或先用 2.0-mini、2.0-fast 测试），参数 16:9、720p、30 秒，然后生成。

### 第 5 步：剪辑
1. 在画布里批量下载视频节点的视频。
2. 导入剪映，按视频编号排好，加配乐、音效和字幕，导出。
